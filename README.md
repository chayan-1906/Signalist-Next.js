## 🎯 Overview

**Signalist** is a modern stock market tracking platform built for investors who want real-time data, actionable insights, and personalized market intelligence—all in one place.

Powered by **Finnhub API** for live market data and **TradingView** for professional-grade charting, Signalist combines robust financial data with an AI-driven personalization engine that delivers
tailored welcome messages and daily news summaries directly to your inbox.

## 🚀 Getting Started

### Prerequisites

Ensure you have the following installed:

- **Node.js** 18.x or higher
- **npm**
- **MongoDB** instance (local or Atlas)

### Installation

1. **Clone the repository**

   ```bash
   git clone https://github.com/chayan-1906/Signalist-Next.js.git
   cd Signalist-Next.js
   ```

2. **Install dependencies**

   ```bash
   npm install
   ```

3. **Configure environment variables**

   Copy the example environment file and fill in your credentials:

   ```bash
   cp .env.example .env
   ```

4. **Set up environment variables**

   ```env
   # App Configuration
   NODE_ENV=development
   NEXT_PUBLIC_BASE_URL=http://localhost:3000

   # Database (MongoDB Atlas recommended)
   MONGODB_URI=mongodb+srv://username:password@cluster.mongodb.net/signalist

   # Authentication (Better Auth)
   BETTER_AUTH_SECRET=your-secret-key-minimum-32-characters-long
   BETTER_AUTH_URL=http://localhost:3000

   # Google Gemini AI (for personalized emails)
   GEMINI_API_KEY=your-gemini-api-key

   # Finnhub Stock API (https://finnhub.io/)
   NEXT_PUBLIC_FINNHUB_API_KEY=your-finnhub-api-key

   # Email Configuration (Gmail with App Password)
   NODEMAILER_EMAIL=your-email@gmail.com
   NODEMAILER_PASSWORD=your-16-char-app-password
   NEXT_PUBLIC_SUPPORT_EMAIL=support@yourdomain.com
   ```

5. **Start the development server**

   ```bash
   npm run dev
   ```

6. **Start Inngest Dev Server** (for background jobs)

   ```bash
   npx inngest-cli@latest dev
   ```

7. **Open the app**

   Navigate to [http://localhost:3000](http://localhost:3000)

## 🔧 Core Features

### 📊 Dashboard

The dashboard provides a comprehensive market overview with embedded TradingView widgets:

- **Market Overview** — 12-month price action for major indices
- **Stock Heatmap** — Visual sector-based market performance
- **Top Stories** — Real-time market news timeline
- **Market Quotes** — Live quotes across financial, tech, and service sectors

### 📈 Stock Details

Deep-dive into any stock with professional analysis tools:

- **Symbol Info** — Company name, exchange, and basic info
- **Candlestick Chart** — Daily OHLC price action
- **Baseline Chart** — Long-term trend visualization
- **Technical Analysis** — Key indicators and signals
- **Company Profile** — Business description and fundamentals
- **Financials** — Key financial metrics and ratios

### ⭐ Watchlist Management

- Add stocks directly from search or stock detail pages
- View real-time prices, changes, market cap, and P/E ratios
- Remove stocks with one click
- Unique constraint prevents duplicates

### 🤖 AI-Powered Personalization

- **Welcome Emails** — AI-generated personalized introductions based on user preferences
- **Daily News Digest** — Automated 12 PM UTC emails with curated news from watchlist stocks
- **Preference-Based** — Content tailored to investment goals, risk tolerance, and industry preferences
